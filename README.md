# Terra Massatge · web

Web one-page estática (HTML, CSS y JavaScript sin build) de Terra Massatge, quiromasaje y bienestar en Carcaixent.

- Verla en local: `npx serve .`
- Despliegue: Netlify publica la raíz del repositorio (ver `netlify.toml`).
- Datos editables en un solo sitio: objetos `CONTACTO`, `RITUALES`, `DATOS` y `HORARIO` al principio de `main.js`.
- Las reseñas de Google están escritas a mano en `index.html` (sección Opiniones).
